# documento funzionale 
progetto di learn per imparare a strutturare un progetto cpmplesso mediante la creazione di un sistema di gestione delle carte.

per avere un idea di avanzamento, il progetto viene gestito in maniera incrementale partendo da un archittetura a moduli monolitica per poi evolvere con successive versioni in un archittetura distribuita per aumentare la resilienza del sistrema dividendo i moduli in componenti separati.

## requisiti funzionali utente
sistema per: 
    - gestione delle carte di pagamento
    - pagamenti
    - lista transazioni
    - promozioni
